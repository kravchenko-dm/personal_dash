Personal Dash — Политика конфиденциальности

Обновлено: 8 ноября 2026 г.

Personal Dash — это личный дашборд для одного пользователя (владельца), развёрнутый на его собственном сервере. Приложение не является публичным сервисом, не имеет регистрации и не обслуживает третьих лиц.

Какие данные Google используются

При подключении Google Calendar приложение запрашивает права calendar.readonly (чтение списка календарей и событий) и calendar.events (создание событий). Данные используются только для того, чтобы показать владельцу его агенду на дашборде, в утреннем брифе и в Telegram-боте, а также создать событие по его команде.

Хранение

OAuth-токены хранятся в базе данных на сервере владельца и используются только для обращения к Google Calendar API от его имени. События кэшируются в памяти на время запроса и не сохраняются постоянно.

Передача третьим лицам

Данные Google Calendar не продаются, не передаются рекламным сетям и не используются для обучения моделей. Фрагменты расписания могут включаться в текст, который приложение отправляет выбранной владельцем нейросети для составления утреннего брифа, и в сообщения Telegram-бота самому владельцу.

Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа

Доступ можно отозвать в любой момент кнопкой «Отключить» в настройках дашборда или на странице myaccount.google.com/permissions. После этого токены удаляются из базы приложения.
